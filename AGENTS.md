# Contexto de ServiPronto

Antes de realizar cambios de producto en este proyecto, leer completamente `README.md`, `docs/PRODUCTO.md`, `docs/DECISIONES.md` y `.specify/memory/constitution.md`. Para especificaciones o desarrollo, consultar también `ROADMAP.md`.

- El descubrimiento inicial ya fue realizado en 24 tandas. El fundador preguntó cuánto faltaba y previamente pidió conservar la información. Se consideró suficiente esta base para cerrar el descubrimiento inicial; no reiniciarlo ni repetir preguntas respondidas.
- Mantener separadas las decisiones confirmadas, las propuestas delegadas, los supuestos y las validaciones pendientes. Las instrucciones actuales del fundador pueden modificar estos documentos.
- Usar GitHub Spec Kit para especificar y desarrollar; preparar cada funcionalidad con un alcance manejable. El estado inicial de esta carpeta es documental, no una instalación operativa de Spec Kit ni una aplicación.
- El fundador no quiere aprobaciones rutinarias para cada especificación, plan o tarea. Resolver decisiones reversibles con criterio y consultar únicamente elecciones materiales no cubiertas por el contexto.
- La aplicación debe funcionar sin usar a Jorge. Jorge representa un asistente de IA con personalidad de castor, no una persona humana; su identidad cálida no autoriza a fingir acciones, verificaciones ni resultados.
- Antes de especificar o modificar Jorge, leer también `docs/ARQUITECTURA_JORGE.md`. Mantener contrato propio, gateway y adaptadores de IA aislados; no acoplar preparación, orquestadores ni reglas de negocio a SDK de un proveedor. La independencia exige pruebas, no promete compatibilidad universal.
- Contrataciones, cambios de precio y pagos requieren autorización explícita apropiada. La confirmación de una etapa y la disponibilidad del dinero en Mercado Pago son estados diferentes.
- Conservar las prioridades de equipo pequeño, simplicidad, acceso para adultos mayores, contratación familiar, identidad visual y pagos trazables sin prometer control de acuerdos externos.
- Comunicar en español rioplatense claro, con explicaciones breves y orientadas al producto.
